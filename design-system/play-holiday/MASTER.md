# Play Holiday 移动端设计系统

> 来源：`ui-ux-pro-max` 的 Hyperlocal Services、Flat Design Mobile、移动端触控／无障碍规则与 React 性能规则；Anthropic `frontend-design` 用于视觉独特性复核。技能自动生成的“App Store Landing／No map”与小程序任务冲突，已按技能规则舍弃。

## 1. 设计命题

这是武汉钓友在户外、强光、湿手、弱网环境里使用的**出钓决策工具**，不是内容社区。界面优先回答“今天去哪、是否能钓、最近有没有真实趟次”，视觉应像可靠的户外仪表，而不是紫色 SaaS 后台。

独特元素是“水线状态条”：每张水域卡用一条细水线同时编码数据新鲜度和现场状态，并配文字标签；它是信息，不是装饰。其余界面保持克制。

## 2. 设计方向

- 模式：Flat Touch-First + Hyperlocal Map。
- 变异度：4/10；动效：2/10；密度：6/10。
- 无渐变、无玻璃拟态、无装饰性阴影；层级依靠底色、边框、间距和字号。
- 卡片圆角 24rpx，按钮圆角 20rpx，状态标签使用胶囊形。
- 只使用有因果意义的 150–220ms 透明度／位移动效；微信系统减少动态效果时取消非必要动效。

## 3. 颜色 Token

| Token | 色值 | 用途 |
| --- | --- | --- |
| `brand-primary` | `#126B57` | 主按钮、选中态、已核实 |
| `brand-pressed` | `#0D5747` | 按压态 |
| `water-blue` | `#1976A3` | 地图、水位、信息状态 |
| `sun-amber` | `#B85C00` | 条件允许、天气提醒 |
| `danger` | `#B42318` | 禁止、高风险、错误 |
| `ink` | `#14231F` | 主文本 |
| `ink-secondary` | `#4B625B` | 次文本，须满足对比度 |
| `canvas` | `#F3F7F5` | 页面背景 |
| `surface` | `#FFFFFF` | 内容表面 |
| `surface-tint` | `#E6F2EE` | 选中／轻提示背景 |
| `border` | `#D7E2DE` | 边框和分隔线 |

状态不能只靠红绿区分，必须同时出现文字或图形。正文与背景对比度至少 4.5:1。

## 4. 字体与数字

- 使用微信系统中文字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`；不加载 Google Font。
- 页面标题 40rpx/700，区块标题 32rpx/650，正文 28rpx/400，辅助 24rpx/400，最小正文不低于 24rpx。
- 天气、距离、趟次数使用等宽数字特性，避免刷新跳动。
- 文案用用户语言：“记一趟”“最近有口”“样本不足”，不用“Submit”“数据上报”等系统术语。

## 5. 间距、触控与安全区

- 4/8pt 节奏映射到 8/16rpx 基础单位；页面横向边距 32rpx。
- 所有主要可点击区域至少 96×96rpx，邻近目标间隔至少 16rpx。
- 固定底部操作区必须叠加 `env(safe-area-inset-bottom)`；滚动内容预留 TabBar 空间。
- 页面在 375px 小屏和横屏下不可横向溢出；地图筛选过多时使用显式横向滚动，不挤压文字。

## 6. 导航与页面规则

- 四个原生 Tab：出钓、地图、记录、我的；图标和文字同时存在。
- 首页主 CTA 只有“记一趟”；地图主 CTA 是“回到定位／在这里记录”中的当前任务动作。
- 水域卡进入详情，返回时保留地图视野、筛选和选中水域。
- 权限按动作请求：启动时不索取定位、相机和相册权限。

## 7. 组件规则

### 水域卡

- 第一行：名称、距离、规则状态。
- 第二行：近 7 天实际趟次数、最近确认时间；样本不足不显示百分比。
- 水线状态条：实线表示已核实，虚线表示用户报告；颜色之外必须有状态文字。
- 卡片整体可点击，内部次操作不得形成小于 96rpx 的点击目标。

### 状态标签

- `允许参考`：品牌绿 + 对勾形语义；
- `条件允许`：琥珀 + “需看规则”；
- `禁止／高风险`：危险红 + 禁止语义；
- `待核实`：灰蓝 + 问号语义。

### 加载与错误

- 300ms 内不闪烁加载器；超过 300ms 显示保留尺寸的骨架。
- 错误说明原因和恢复动作，例如“天气暂时没更新，查看缓存（08:20）”。
- 弱网不阻止记录，显示“已保存在本机，联网后同步”。

## 8. 图标与动效

- 使用统一圆角线性图标，视觉尺寸 44–52rpx，结构图标不用 emoji。
- 按压反馈 80–150ms 内出现，以透明度或底色变化为主，不改变布局边界。
- 不在地图上做循环跳动标记，不用热力红色诱导进入禁止或高风险区域。

## 9. 交付前检查

- 所有触控目标 ≥96rpx；正文对比度 ≥4.5:1。
- 图标均有文字或可访问名称；状态不只靠颜色。
- 拒绝定位、弱网、无数据、样本不足、禁止垂钓均有独立界面状态。
- 375px、常见大屏、横屏和系统大字号不遮挡主动作。
- 原生 TabBar 和固定 CTA 不覆盖滚动内容；生产包关闭调试面板。
